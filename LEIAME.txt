INSTRUÇÕES DE ATUALIZAÇÃO (DuoFin 2 v2.9.1 — Envio Automático de Emails de Convite via Edge Function)

1. PUBLICAR A EDGE FUNCTION NO SUPABASE (`send-household-invite`):
- No painel do Supabase -> Edge Functions -> Create a new function -> Nome exato: `send-household-invite`
- Cola o conteúdo do ficheiro `supabase/functions/send-household-invite/index.ts` incluído neste ZIP e clica em Deploy.
- Vai a Edge Functions -> Secrets (ou Project Settings -> Edge Functions) e adiciona:
  • `RESEND_API_KEY`: a tua chave gratuita de resend.com (recomendado: envia emails tanto para contas novas como para utilizadores que já criaram conta no Supabase).
  • `RESEND_FROM_EMAIL` (opcional): ex. `DuoFin 2 <onboarding@resend.dev>` ou o teu domínio verificado.
  (Nota: Se não definires `RESEND_API_KEY`, a função tenta usar automaticamente o `supabase.auth.admin.inviteUserByEmail` nativo do Supabase.)

2. SUBSTITUIÇÃO DOS FICHEIROS NO GITHUB / PROJETO:
Extrai este ZIP diretamente para a pasta raiz do teu projeto DuoFin 2 (substituindo os ficheiros existentes):
- index.html                                           -> Raiz do projeto (v2.9.1)
- sw.js                                                -> Raiz do projeto (Cache PWA v2.9.1)
- js/config.js                                         -> Pasta js/ (Versão v2.9.1)
- js/supabase-sync.js                                  -> Pasta js/ (Invocação automática da Edge Function `send-household-invite`)
- js/app.js                                            -> Pasta js/ (Feedback visual de envio de email automático)
- supabase/functions/send-household-invite/index.ts    -> Código completo da Edge Function para o Supabase
